
## How to Contribute

1. **Fork** the repo 🍴
2. **Clone** your fork: `git clone https://github.com/YOUR-USERNAME/GoBlox.git`
3. **Branch** off main: `git checkout -b my-cool-feature`
4. **Make** your changes ✨
5. **Commit** with a clear message: `git commit -m "add: new block behavior"`
6. **Push** and open a **Pull Request** 🚀

## Adding a New Block

1. Create `blocks/YourBlock.xml` 🧱
2. Follow the format of existing block XML files 📝
3. Update the manifest if needed
4. Test against the Go server in `server/` 🐹
5. Open a PR!

## Code Style

- Go: `gofmt` everything, honey! 🧹
- XML: 2-space indents, tidy tags 🧱
- JSON5: comments welcome! 💬
