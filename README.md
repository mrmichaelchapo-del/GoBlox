# GoBlox 🐿️

A desktop app platform built around XML blocks and a Go backend.

## Project Structure
```
GoBlox/
├── package.json5      # App manifest (JSON5)
├── blocks/            # Block XML definitions
│   └── YourBlock.xml  # The block format and what it does
├── server/            # Go backend
└── ...                # The desktop app itself
```

## What is GoBlox?

GoBlox is a programming environment for building desktop applications
using XML-defined blocks, powered by a Go backend.
